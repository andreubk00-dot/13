# Живой лабиринт · Убежище

Первый играбельный прототип браузерной 2D-игры о строительстве базы и экспедициях. Движок **Phaser 3**, язык **TypeScript**, сборка **Vite**. Художественные элементы рисуются программно; шрифты поставляются с игрой и не требуют внешнего CDN.

## Запуск

Нужен Node.js 22.18+ (проверено на 24.19) и npm.

```bash
cd /workspace/13
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

Для production: `npm run build`. Статические файлы находятся в `dist/`. Для внутренней проверки сборки: `npm run preview -- --port 4173`.

Используйте существующий checkout. Облачные задачи уже изолированы; создавать Git worktree для запуска не нужно.

## Что можно делать

Игрок начинает без материалов. Рубите деревья и добывайте камень и руду. Создайте каменное копьё, постройте дом по клеткам, установите печь и кузницу. Отправляйтесь за разлом, победите стражей и соберите три разные части чертежа реликтового клинка бурь.

- WASD / стрелки: движение. E: добыча и станции.
- Space / щелчок по миру: удар. Shift: рывок с короткой неуязвимостью.
- B / 3: строительство. Выбор элемента в панели, затем щелчок по клетке в пределах четырёх клеток от игрока.
- C / 4: крафт. 5: карта и источники частей чертежа.
- Esc: отменить выбранную постройку. Крестик закрывает панель.
- Кнопка паузы: продолжение / новый мир с подтверждением удаления.
- На телефоне: кнопки движения и действий. После выбора постройки закройте панель и коснитесь клетки.

## Строительство и износ

Для защищённой станции нужны пол и крыша над **всеми внутренними клетками** замкнутого помещения, ограниченного стенами или дверями. Двери проходимы. Например, квадрат 5×5 со стенами по периметру, одной дверью и внутренним полом/крышей 3×3.

Печь и кузница расходуют 2% прочности за операцию внутри такого здания и 4% снаружи. Во время простоя износа нет. При 0% станция перестаёт работать; ремонт за 2 древесины и 2 камня возвращает 100%. Сундук не изнашивается. Ошибочные постройки можно разобрать; материалы не возвращаются. Разбор снимает сначала крышу, затем станцию, затем ограждение/пол.

Печь: 10 камня + 4 древесины. Один слиток: 2 руды + 1 древесина. Кузница: 8 камня + 6 древесины + 3 железа. Броня: 5 железа + 4 древесины. Клинок: изученный чертёж + 8 железа + 3 искры.

## Экспедиции и сохранения

Постоянный мир расположен слева от светящегося разлома. Справа — меняющиеся каменные проходы, ресурсы, стражи и руины. Возвращение через границу перестраивает опасную сторону, восстанавливает её находки и стражей и возвращает 25 здоровья. База и собранные ресурсы постоянной стороны сохраняются.

Основа чертежа: старая кузница в северной части лабиринта. Механизм: стражи. Сердце: юго-восточные глубинные руины. Руины нельзя открыть, пока рядом жив страж. Для изучения нужна одна часть каждого вида. Дубликат разбирается в одну обычную древесину; обмена на недостающие части нет. Пока чертёж не изучен, разбор сохраняет по одной нужной части.

При гибели теряется половина каждого материала и все части чертежей в рюкзаке. База, содержимое сундука, снаряжение и изученный чертёж сохраняются. Сундук имеет общее хранилище материалов; E открывает операции «Убрать всё» / «Забрать всё».

Автосохранение: localStorage текущего браузера/домена каждые пять секунд, после важных действий и при уходе со страницы. Это **не облачное сохранение**. При смене домена или очистке браузера прогресс не переносится. При недоступном хранилище HUD сообщает об этом.

## Проверки

```bash
npm test
npm run build
```

Браузерные проверки требуют работающего сервера разработки и Chromium:

```bash
npm run test:browser
```

По умолчанию Chromium: `/usr/bin/chromium`; переопределение: `CHROMIUM_PATH`. Адрес сервера: `GAME_URL`. Скриншоты тестов создаются в игнорируемом `artifacts/`. Проверка gameplay использует отдельные подготовленные сохранения **только внутри тестового браузера**, чтобы воспроизвести строительство, износ, крафт, бой и смену мира; в игру не встроена выдача ресурсов.

## Границы прототипа

Это вертикальный срез, не законченная игра. Есть восемь видов строительства, два создаваемых оружия, один комплект брони, один составной чертёж, обычные стражи и усиленный хранитель. Анимации включают движение, удары, попадания, рубку, частицы строительства, дым печи и покачивание деревьев.

Пока нет SDK Яндекс/VK, рекламы, облачных сохранений, платформенной авторизации, нападений на базу, фракций, адаптации города к стилю игрока, большого каталога рецептов и полноценной балансировки длительных сессий. «Цикл» обозначает перестройку после возвращения, а время суток в HUD — пока визуальный индикатор. Обычная добыча сейчас состоит из ресурсов и частей чертежей; выпадение базового готового снаряжения оставлено следующему этапу. Нужны отдельная интеграция выбранной площадки, тестирование устройств и дальнейшее согласование новых игровых систем.

## GitHub Pages

Сборка настроена на относительные адреса и работает в каталоге проекта `/13/`.

```bash
npm run pages:prepare
```

Команда собирает игру и копирует готовые статические файлы в `docs/`, включая `.nojekyll`. Для размещения в GitHub Pages используйте **Settings → Pages → Deploy from a branch → main → /docs → Save**. Каталог `docs/` содержит публичную сборку без секретов и node_modules; после изменения игры повторите подготовку и отправьте обновлённые файлы в репозиторий. Старые хешированные ассеты команда не удаляет, чтобы не удалять пользовательские файлы.

Планируемый адрес: `https://andreubk00-dot.github.io/13/`. Этот адрес становится рабочим только после успешной активации и публикации GitHub Pages. Сохранение настроек облачной среды не включает GitHub Pages.
