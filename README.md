# Живой лабиринт · Убежище

Браузерная 2D-игра на **Phaser 3 + TypeScript**, сборка Vite. Версия 05 добавляет бег из редактируемого скелета Blender и физику разгона, торможения и поворотов. SVG-иконки, персонажи и элементы мира нарисованы для игры; шрифты входят в сборку.

## Разработка

Node.js 22.18+ (проверен 24.19), npm.

```bash
cd /workspace/13
npm ci --cache /workspace/.npm-cache
npm run dev -- --port 5173
```

Используйте существующий checkout: облачная задача уже изолирована, Git worktree для запуска не нужен. `npm run build` создаёт production-сборку в `dist/`. `npm run preview -- --port 4173` запускает её для внутренней проверки.

## Первые шаги

Начинайте с пустыми руками. Подойдите к дереву, камню или руде и нажимайте **E**. Постройте печь за 10 камня и 4 древесины. У печи переплавьте руду: 2 руды + 1 древесина → 1 железо. Постройте кузницу за 8 камня, 6 древесины и 3 железа. Создайте в ней копьё, затем экипируйте его в рюкзаке.

Снаряжение, изучение чертежей и разбор дубликатов доступны **только у рабочей кузницы**. Плавка выполняется только у печи. Общего меню «Мастерство» и карманного крафта снаряжения нет. Созданные вещи появляются в рюкзаке; надевание выполняется отдельно.

На телефоне доступны кнопки движения и действий; они скрываются при открытом игровом окне, чтобы не перекрывать его. Выберите сооружение, нажмите «Разместить», затем коснитесь клетки.

## Строительство

Меню разделено на дом, мастерские и ограду. Стены, двери и заборы подстраиваются под соседние секции: прямые отрезки, углы, ответвления и пересечения. R задаёт направление отдельной секции; соединённые соседи определяют её форму автоматически. Толщина стен и заборов учитывается в столкновениях. Двери открываются при приближении.

Для защищённой станции нужны замкнутые стены с дверью, пол и крыша над всеми внутренними клетками. Основание и крыша визуально доходят до стен без травяных щелей. Крыша становится прозрачной, когда персонаж внутри.

Печь и кузница расходуют **2% прочности внутри здания и 4% снаружи** за операцию. Во время простоя износа нет. При 0% станция не работает. Ремонт за 2 древесины и 2 камня восстанавливает 100%. Сундук не изнашивается.

«Разобрать» снимает сначала крышу, затем станцию, затем стену/забор/пол. Материалы не возвращаются. После удаления и добавления стены соседние секции и защита помещения пересчитываются.

## Рюкзак и экипировка

Базовый рюкзак имеет 24 клетки, материалы и части чертежей собираются в стеки до 99. Предметы можно переставлять перетаскиванием или оставить на земле и подобрать через E. Если рюкзак заполнен, добыча стража остаётся на земле и не исчезает; ресурсы и части из руин не забираются, пока для них нет места. Снаряжение имеет отдельные слоты оружия, головы, корпуса и ног. Снятый предмет возвращается в рюкзак, заменённый предмет не исчезает. Защита рассчитывается по реально надетым частям.

Хотбар содержит восемь настраиваемых клеток. Перетащите туда снаряжение, материал или карточку постройки. Оружие в хотбаре можно экипировать соответствующей цифрой. Материал открывает его описание в рюкзаке, строительный элемент сразу включает размещение.

Сундук хранит материалы и части чертежей, защищая их при гибели. Для работы с сундуком нужно подойти к нему и нажать E. Содержимое общее для сундуков текущей базы. Экипировка не убирается кнопкой «Убрать материалы».

## Мир и чертежи

Мир расширен с 44×32 до **76×52 клеток**: тихая опушка, старый лес, затерянный город, пепельный карьер и туманные низины. Слева от разлома земля постоянна; справа ресурсы, стражи и проходы меняются после возвращения. База остаётся на месте. Перестройка возвращает 25 здоровья.

Чертёж клинка бурь состоит из трёх частей: основа находится в старых кузницах, механизм — у стражей, сердце — в глубинных руинах. Руины нельзя открыть, пока рядом жив страж. Соберите части, вернитесь к кузнице и изучите чертёж. Затем изготовьте клинок за 8 железа и 3 искры.

**Обмена дубликатов на недостающие части нет.** Разбор в кузнице даёт по одной обычной древесине за лишнюю часть. Пока чертёж не изучен, по одной нужной части сохраняется.

## Персонаж и анимация

Персонаж отрисовывается как отдельная модель с двухзвенными руками и ногами. Решатель ограничивает досягаемость кистей и стоп и сохраняет длины костей; колени сгибаются в плоскости движения. Плечи, шея и броня используют общий поворот корпуса. Направление модели меняется по кратчайшей дуге; в бою поворот завершается к моменту контакта. Шаги считаются по реальному перемещению, имеют опору и перенос стопы; ключевые позы соединены кривыми с непрерывной скоростью. Копьё делает выпад, клинок — рубящий удар, кулак — короткий удар. Шарф следует за движением с задержкой, голова компенсирует наклон корпуса, а след клинка строится по положениям его кончика. Голова, корпус, шарф, сумка и надетое снаряжение следуют за позой; поворот меняет профиль и порядок слоёв. Дыхание, ходьба, удар, добыча, рывок, получение урона, строительство, работа у станции, подбор и подъём после возрождения имеют собственные позы и время движения. При упоре в стену шаги прекращаются.

Удар и добыча имеют замах: контакт, звук и результат происходят через 120 мс игрового времени. Пауза останавливает анимацию и контакт; рывок отменяет незавершённый замах. В открытом окне станции проигрывается рабочая анимация, а мир остаётся остановленным. Без снаряжения герой добывает материалы руками. Размер динамической текстуры — 208×208; внешние изображения и большие атласы не нужны.

## Бег и редактор персонажа · версия 05

Для бега создана оригинальная сцена **Blender 4.3.2** с моделью, костями, IK-контроллерами стоп/кистей и циклами `Run`, `Run_Armed`, `Idle`. Положения костей экспортируются в игру; браузер сохраняет минималистичную 2D-отрисовку. Платный редактор или новый движок не требуются. Инструкции: [assets/character/README.md](assets/character/README.md).

Управление имеет разгон, торможение и инерцию при смене направления. Физика обновляется с шагом 1/120 секунды, диагональ не ускоряет игрока. Столкновение прекращает движение в препятствие и сохраняет движение вдоль стены. Фаза бега связана с фактическим пройденным путём; скорость управляет переходом в покой, ускорение добавляет наклон корпуса. Бег содержит амортизацию, толчок и фазу полёта. При оружии руки двигаются с меньшим размахом.

После публикации исходник доступен по адресу https://andreubk00-dot.github.io/13/downloads/hero.blend, инструкция — https://andreubk00-dot.github.io/13/downloads/character-guide.md.

## Сохранения

Прогресс хранится в localStorage текущего браузера/домена. Автосохранение происходит каждые пять секунд, после важных действий и при уходе со страницы. При гибели теряется половина материалов и все части чертежей в рюкзаке; база, сундук, снаряжение и знания сохраняются.

Сохранения первой версии автоматически переводятся в новую модель экипировки без удаления базы и ресурсов. Перед миграцией сохраняется локальная резервная копия исходного сохранения. Прогресс пока не переносится между устройствами и доменами.

## Проверки

```bash
npm test
npm run build
npm run test:browser
```

Для браузерных проверок должен работать сервер разработки. Chromium по умолчанию: `/usr/bin/chromium`, другой путь задаётся через `CHROMIUM_PATH`. Адрес сервера задаётся через `GAME_URL`. Тесты используют собственный браузер и подготовленные сохранения, затем строят дом через реальные кнопки и щелчки, проверяют стены, дверь, крышу, кузницу, рюкзак и восстановление прогресса. Скриншоты создаются в игнорируемом `artifacts/`. В самой игре нет выдачи тестовых ресурсов.

Статическая земля растрируется один раз в небольшие текстуры по 512 пикселей, чтобы расширение мира не заставляло каждый кадр рисовать все его детали и не требовало больших GPU-текстур на телефонах.
