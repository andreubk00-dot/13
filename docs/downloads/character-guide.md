# Персонаж и бег в Blender

`hero.blend` — оригинальная редактируемая сцена Blender 4.3.2: геометрия человека, материалы, скелет, IK-контроллеры и анимации. Игра использует экспортированные положения костей, сохраняя свою 2D-отрисовку. Blender не нужен игроку и не запускается в браузере.

## Открытие и редактирование

1. Установите бесплатный Blender: https://www.blender.org/download/.
2. Откройте `hero.blend`, выберите `Hero_Rig`, переключитесь в **Pose Mode**.
3. В рабочем пространстве **Animation**, в **Dope Sheet → Action Editor** выберите `Run`, `Run_Armed` или `Idle`.
4. Кадры **1–36** образуют цикл, кадр 37 повторяет начало. Нажмите Space для просмотра. Стопы и кисти управляются костями `foot_ik.L/R` и `hand_ik.L/R`; направление сгибания задают `knee_pole.L/R` и `elbow_pole.L/R`.
5. Для изменения модели выберите отдельную деталь тела в Object Mode и переходите в Edit Mode. Геометрия оригинальная, детали прикреплены к костям. Сохраните файл после изменения.
6. Экспортируйте отредактированную анимацию командой ниже, затем соберите игру. **`character:build` пересоздаёт исходник с нуля; для сохранения ручных правок используйте `character:export`.**

```bash
npm run character:export
npm run build
```

## Воспроизводимое создание с нуля

```bash
npm run character:build
```

`build_character.py` создаёт геометрию, материалы, скелет, ограничения суставов и ключи анимации. `export_animation.py` считывает окончательные положения костей после вычисления Blender IK и создаёт `run-cycle.json` и `src/generated/run-cycle.ts`. В браузере Blender заменён компактными данными анимации.

У `Hero_Rig` есть Custom Properties `cycle_distance` (метры за цикл) и `metres_to_pixels`. Если меняете длину шага, обновите `cycle_distance`, чтобы стопа в опорной фазе соответствовала скорости движения мира.

## Физика и анимация

Физическое перемещение выполняется с постоянным шагом 1/120 секунды: разгон 1050 пикселей/с², торможение 1550 пикселей/с², предельная скорость 185 пикселей/с. Диагональ нормализуется. Столкновение обнуляет заблокированную компоненту скорости. Длина пройденного пути задаёт фазу бега, скорость — смешивание с покоем, ускорение — дополнительный наклон корпуса.

В цикле есть контакт, амортизация, толчок, перенос ноги и фаза полёта с обеими стопами над землёй. Движение рук противоположно движению ног; при удержании оружия размах правой руки уменьшен. Кости не растягиваются, стопа получает отдельную ориентацию для переката.

Модель и скелет принадлежат этому проекту; платные библиотеки, внешние модели и лицензия Spine не используются.
